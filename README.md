# hxwl-10 探方编号牌领用归还台

考古探方页的编号牌管理：按发掘季建牌、领用登记、验收归还、旧季号码重投核查与全程台账。

## 技术栈

React + Vite + TypeScript + CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5110

## 功能

- 建牌：牌按发掘季建，牌号全季不重复
- 领用：写明探方、地层、遗迹单位与领用人，一块牌跟一个遗迹单位
- 归还：遗迹单位验收退场后归还，牌面状态一并记下
- 旧季号码重投：重投前确认没有未结束的关联，有未归还领用则拦下
- 冲突提示：重复领用或未归还时，页面指出牌号、原探方和原领用人
- 台账：每次领用归还都留痕，存于本机 localStorage，重开可追

## 分层

- `src/data/seed.ts` — 资料：探方、地层、遗迹单位、队员名录与初始台账
- `src/rules/plateRules.ts` — 规则：建牌查重、领用、归还、重投的纯函数校验
- `src/store/ledger.ts` — 本机记录：台账读写 localStorage，与资料、规则分开
